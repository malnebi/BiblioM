# БиблиоМ

БиблиоМ је веб-апликација за управљање књигама, библиотекама и позајмицама. Апликација је изграђена помоћу Laravel-а.

## Локално покретање

Потребни су PHP 8.2+, Composer, Node.js и npm.

```sh
composer install
cp .env.example .env
php artisan key:generate
touch database/database.sqlite
php artisan migrate
php artisan storage:link
npm install
npm run dev
```

У другом терминалу покренути веб-сервер:

```sh
php artisan serve
```

Примјер конфигурације користи SQLite. За MySQL или други подржани систем, подесити одговарајуће `DB_*` вриједности у `.env` прије покретања миграција.

## Постављене слике

Фотографије корисника, логотипи библиотека и корице књига чувају се на Laravel `public` диску у `storage/app/public`. Да би били доступни у прегледачу, потребно је да постоји симболичка веза `public/storage` ка том директоријуму. Направити је једном за свако окружење:

```sh
php artisan storage:link
```

При deploy-у на серверу покренути ову команду из директоријума апликације и провјерити да PHP процес може да уписује у `storage/app/public`. Ако deploy користи нови директоријум за сваку верзију апликације, `storage/app/public` треба да буде трајан директоријум који се дијели између верзија; у супротном већ постављене слике неће бити доступне након deploy-а. Ако симболичка веза већ постоји, али је неисправна, може се поново направити командом `php artisan storage:link --force`.

## Потврда мејл адресе

Након што администратор одобри регистрацију, кориснику се шаље порука добродошлице са потписаним линком за потврду мејл адресе. Линк важи 60 минута; пријава је омогућена након потврде адресе. Постојећи одобрени налози задржавају приступ, док се провјера примјењује на нове регистрације и захтјеве који су чекали одобрење приликом увођења ове измјене.

За стварну испоруку порука подесити `MAIL_MAILER`, `MAIL_HOST`, `MAIL_PORT`, `MAIL_USERNAME`, `MAIL_PASSWORD`, `MAIL_ENCRYPTION` и `MAIL_FROM_ADDRESS` у `.env`. Примјер локалне конфигурације користи `MAIL_MAILER=log`, па се поруке уписују у лог умјесто слања.
